🇺🇸 US States Guessing Game

A Python game where players try to guess the 50 US states using an interactive map.

🎮 Gameplay

"US States Guessing Game" (game.gif)

✨ Features

- Interactive US map that displays correctly guessed states.
- Score tracking to keep track of progress.
- Saves the missing states to a CSV file when the player exits the game.

🛠️ Technologies Used

- Python
- Turtle Graphics
- Pandas
- CSV file handling

🚀 How to Run

1. Install Python.
2. Install Pandas using "pip install pandas".
3. Make sure the required CSV data file and map image are available.
4. Run "main.py".
